# Checklist de gravação — CURIE Sprint 1

Roteiro para uma demonstração objetiva de aproximadamente 4 a 5 minutos. Grave o aplicativo real em um dispositivo/emulador; não use capturas simuladas. Identifique como demonstrativos todos os dados de medição e mapa.

## Antes de gravar

- [ ] Confirmar build e execução do app no Android usado para a gravação.
- [ ] Ativar gravação de tela e ocultar notificações pessoais.
- [ ] Iniciar em uma sessão limpa, com progresso conhecido.
- [ ] Testar navegação, botões e rolagem nas telas que serão mostradas.
- [ ] Deixar visível o nome CURIE e a turma 2TDSPB na apresentação, se aplicável.

## Sequência sugerida

| Tempo | Demonstração |
| --- | --- |
| 0:00–0:25 | Apresentar CURIE, objetivo educativo, FIAP Challenge 2026 e equipe. |
| 0:25–0:55 | Abrir o app; mostrar boas-vindas e navegar até a Home. |
| 0:55–1:35 | Mostrar Home, progresso e catálogo; abrir uma missão. |
| 1:35–2:20 | Executar a simulação, explicar que a leitura é fictícia e concluir a missão; mostrar pontuação atualizada. |
| 2:20–2:45 | Mostrar mapa colaborativo com registros de demonstração. |
| 2:45–3:10 | Fazer uma pergunta à Marie e mostrar uma resposta local predefinida. |
| 3:10–3:35 | Mostrar conquistas e relação com os pontos da missão. |
| 3:35–4:20 | Enviar formulário inválido para mostrar validação; preencher corretamente e mostrar confirmação. |
| 4:20–4:45 | Encerrar destacando escopo educacional, dados simulados e próximos passos. |

## Revisão do arquivo

- [ ] Áudio compreensível e sem dados pessoais expostos.
- [ ] Texto e controles legíveis; rolagem sem cortes.
- [ ] Missão pontua uma única vez.
- [ ] Formulário mostra erro e confirmação de sucesso.
- [ ] Não afirmar integração com sensor, backend, IA ou persistência.
- [ ] Incluir o link final no README após a publicação autorizada pelo grupo.
